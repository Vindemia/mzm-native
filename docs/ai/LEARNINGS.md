# LEARNINGS

Problèmes et blocages **récurrents** rencontrés en travaillant sur ce projet — liés à la stack, à la façon de travailler, pas des bugs ponctuels. But : ne pas retomber deux fois dans le même trou.

## Ce qui mérite une entrée ici

- Un blocage qui s'est reproduit (ou qui a de bonnes chances de se reproduire) à cause d'une caractéristique de la stack (ex. un piège récurrent avec `agbcc`, avec le scripting mGBA, avec le timing SDL2).
- Un malentendu de fonctionnement qui a fait perdre du temps et qui pourrait retromper à nouveau.

Ce qui **ne va pas ici** : une faute de frappe corrigée, un bug ponctuel sans caractère récurrent, une décision (→ `DECISIONS.md`).

## Format d'une entrée

```markdown
## AAAA-MM-JJ — Titre court du problème

**Symptôme** : ce qu'on observait.
**Cause racine** : pourquoi ça arrivait vraiment.
**Comment l'éviter maintenant** : ce qu'on fait différemment depuis.
```

## À vérifier avant de commencer une nouvelle tâche

Avant d'attaquer un nouveau jalon, relire rapidement les entrées de ce fichier — si une entrée concerne la zone du code sur laquelle on va travailler, l'appliquer dès le départ plutôt que de redécouvrir le problème.
